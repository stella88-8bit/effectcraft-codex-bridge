# Проверка интеграции

22 октября 2026 года подключение проверено на настоящем EffectCraft **0.13.0** на macOS через локальный HTTP API и нативный MCP bridge.

- API на `127.0.0.1:8767` подтвердил состояние и отрендерил существующую композицию **Codex API + MCP 112637** в 960 × 540 на 1,5 секунды.
- MCP согласовал протокол `2025-06-18`, перечислил **36 инструментов** и прочитал ту же активную композицию. Его кадр совпал с API **попиксельно после декодирования в RGB**. PNG API и MCP могут отличаться байтами и режимом RGB/RGBA.
- Уже сохранённые `api-preview.png` и `mcp-preview.png` совпали с новым проверочным кадром в RGB.
- Состояние редактора и сводка проекта до и после проверки совпали. Проверка не создавала, не редактировала, не открывала и не закрывала композиции или проекты; приложение не запускалось и не завершалось.
- **71 автоматический тест пройден** на Python 3.12.14 и 3.15.0. Этот результат относится к отдельному полному запуску unittest; проверка открытого приложения не входит в изолированные тесты.

Машиночитаемые результаты и SHA-256 изображений сохранены в сопровождающем демонстрационном пакете `verification.json`. Реальная проверка проведена на macOS; Windows/Linux не проверялись вручную. После регистрации нового сервера Codex должен перечитать MCP-конфигурацию; уже открытый чат не получает инструменты автоматически.
